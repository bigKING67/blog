# AI Intelligence Daily｜2026-11-01

**今日判断：** AI 工程越来越强调将可确定的步骤固化为可验证程序、为检索提供证据约束，以及在可控环境内让 Agent 执行代码。视频方向则强调可编辑的显式状态和带时间戳的证据。

**时效说明：** 截至北京时间 11 月 1 日早间，尚未发现足够高价值且可一手核实的 11 月 1 日重大新发布。精选近几日首次发布的研究和产品，并补充一项与视频理解高度相关但于 10 月 4 日发表的论文。下述结果、指标均为作者或厂商自报，未独立复现。

## 01｜SkillCompiler：将 Skills 中可确定的步骤编译成程序（论文 10 月 29 日）

**摘要：** 原始论文提出，将反复执行且规格明确的 Skill 步骤转为可验证程序，保留 LLM 处理仍需情境判断的部分，并构建程序资产复用机制。

**核心解读：** Skills 不必全程依靠模型重新阅读指令、推理和生成命令；确定性环节可成为可测试的软件模块，模糊环节继续交给 Agent。

**为什么值得关注：** 重复操作的推理不确定性、调用成本和失败概率是长期 Agent 工程瓶颈。论文报告最多 32.33% 的性能提升，但只是作者实验。

**对 pi-67 / AIOS 的启发：** 对多次复用的任务步骤建立“规范—程序—测试—失败回退”路径，同时保留不可程序化的判断。先比较错误率与总体成本再决定实现。此研究与网上同名第三方 SkillCompiler 仓库并非已核实的同一项目。

**成熟度：32/100，研究论文。** 一手来源：https://arxiv.org/abs/2610.39508

## 02｜AgenticDS：用类型化契约和证据校验约束 Agent 检索（论文 10 月 29 日）

**摘要：** 南京大学等研究人员公开 AgenticDS 和 HuDS-Bench。系统通过 Planner / Engineer / Critic 将自然语言需求编译为类型化检索计划，结合混合检索、图谱邻居搜索和证据审查。

**核心解读：** Agent 不应只凭相似度或自身判断就宣称候选结果满足硬约束；应保留每条证据的出处、未核实字段和有界修复记录。

**为什么值得关注：** 多 Agent 检索的瓶颈常常是证据可靠性而非检索数量。作者在 HuDS-Bench 上报告 NDCG@10 的改善，尚未独立验证。

**对 pi-67 / AIOS 的启发：** 借鉴契约式工具调用与证据来源分层，用于外部公开资料研究及公开素材检索的质量评估；先评测缺失字段时的拒绝/未知行为。

**成熟度：56/100，早期开源原型。** 一手来源：https://arxiv.org/abs/2610.39608 ；官方代码：https://github.com/nju-websoft/AgenticDS

## 03｜Wizard：世界状态与视频画面解耦的可控生成（论文 10 月 29 日）

**摘要：** Wizard 通过骨骼、几何等结构化代理和显式游戏状态控制视频生成。作者构建了包含 750 场景、178 角色的数据集。

**核心解读：** 把角色动作和世界演变保存在可修改的状态表示中，再将状态作为视频生成条件，可能优于让每段视频隐式记忆全部规则。

**为什么值得关注：** 可交互、跨片段一致的视觉生成，需要世界状态和输出画面的可验证映射。

**对 pi-67 / AIOS 的启发：** 可借鉴角色/场景状态表与镜头生成分层，研究分镜一致性；不能直接将游戏研究推断为商业广告视频生产能力。

**成熟度：33/100，研究论文。** 一手来源：https://arxiv.org/abs/2610.40339

## 04｜Akamai Agent Sandbox：双层 WASM 隔离与默认禁止网络出站（公告 10 月 27 日）

**摘要：** Akamai 发布 Inference 和 Agent Sandbox。Agent 在 Spin WebAssembly 环境中运行，所生成的 JS/Python 代码处于第二层受限运行时，并且网络默认拒绝。

**核心解读：** 代码执行权限应该由 Agent 之外的基础设施强制限制，而不能仅靠 Prompt。基础开源 Spin 与 Akamai 托管技术预览的可用性不能混同。

**为什么值得关注：** 企业多租户 Agent 需要独立的出站网络、资源配额和代码执行边界。

**对 pi-67 / AIOS 的启发：** 研究 WASM sandbox 与 microVM/container 运行时在启动时间、工具兼容性、安全策略和异常隔离上的差别；目前不以厂商自报安全特性代替第三方审计。

**成熟度：54/100，技术预览。** 一手来源：https://www.akamai.com/newsroom/press-release/akamai-launches-ai-inference-service-and-agent-execution-environment ；产品说明：https://www.akamai.com/products/akamai-agent-sandbox

## 05｜VideoResearchAgent：Qwen3.5-4B 驱动的开放网络视频研究（10 月 4 日论文，今日补录）

**摘要：** 论文提出从时间戳证据合成训练任务，通过搜索、观看视频、视觉定位等工具训练视频 Deep Research Agent；采用随机化检索结果减少仿真过拟合。

**核心解读：** 视频检索质量不仅依赖底座 VLM，还取决于工具选择、抽帧策略、证据定位和训练环境是否贴近真实流程。

**为什么值得关注：** 作者报告在 Video-BrowseComp 上用 Qwen3.5-4B 达到 40.48% 准确率，相比未训练基线降低 74.9% 的累计 API Token 消耗；这些是特定任务内部实验，不代表对任意视频理解任务的普遍效果。

**对 pi-67 / AIOS 的启发：** 可先借鉴“粗略概览抽帧→局部密集抽帧→视觉证据定位→自动校验”，不必先做高成本强化学习训练。需要把业务短视频框架拆解建立为独立评测集。

**成熟度：38/100，论文研究。** 一手来源：https://arxiv.org/abs/2610.04911

## 今日评测顺序

优先研究 AgenticDS 的证据约束检索和 SkillCompiler 的确定性技能编译，再把 VideoResearchAgent 的两阶段视频证据获取用于离线小样本评测；Wizard 作为生成控制的研究储备，Akamai 的隔离设计作为安全架构候选。
