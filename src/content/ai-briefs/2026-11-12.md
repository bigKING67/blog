# AI Intelligence Daily｜2026-11-12

**核心判断：** 近期进展显示，多模态 Agent 开始把「高频封闭式决策」从生成式回答中分离；视频生产侧则更重视「先获取镜头证据，再生成/编辑」和受授权的可控改写。日期指北京时间 11 月 12 日收录：前两项为 11 月 11 日官方发布，其余为近期项目首次纳入今日简报，并非均在今日首次发布。

## 1. Gemini Decision 1：多模态封闭式判断 API

**来源发布日期：2026-11-11；类型：模型/API。**

**摘要：** Google 开放 `gemini-decision-1` 的 Gemini Decisions API，支持对同一份文字、图像、音频、视频或 PDF 输入批量进行真假、候选选择和量表评分（最多 1000 个问题，支持最高 256K 输入上下文）。

**核心解读：** 判断型工作流可以不生成长文本；直接返回候选概率，减少格式漂移。不过模型概率并非天然可信，需要在目标数据上校准。

**为什么关注：** 高频任务中镜头类别、商品属性、内容质量等多次判断可能比一次深度推理更消耗总成本。

**pi-67 / AIOS 启发：** 用固定样本比较分类正确率、概率校准、P95 时延与单位合格判断成本；高风险操作仍由外部权限规则管理。

**证据与限制：** 官方价格为 $0.10/百万输入 Token，官方报告端到端 150–250ms（指定配置）；均非独立生产验证。工程成熟度 **81/100**，可评测，不意味着已采用。

一手来源：https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/

## 2. QVAC BotPsy-0.8B：文本工具调用专用小模型

**来源发布日期：2026-11-11；类型：开放权重模型。**

**摘要：** Tether AI Research 发布 0.8B 参数的 BotPsy，基于 Qwen3.5-0.8B 后训练，提供 Apache 2.0 的 BF16/GGUF 权重，重点面向小型设备上的工具选择和多步调用。

**核心解读：** 通过专项后训练，小模型可能更适合大量简单的 Agent 工具动作。但该模型是 **text-only** 工具调用方案，不具备足以替代原生视频理解模型的证据。

**为什么关注：** Agent 的高频小任务需要考虑本地性、响应时间和有效工具调用成本，而非只使用昂贵通用模型。

**pi-67 / AIOS 启发：** 可做本地工具路由与拒绝不适用工具调用的 A/B 测试；不建议用于视频画面框架切分。

**证据与限制：** 官方报告与 Qwen3.5-2B 的部分基准比较结果尚未独立复核。工程成熟度 **69/100**。

一手来源：https://tether.io/news/tethers-800m-ai-agent-beats-models-2-5x-its-size-on-everyday-phone-tasks/ ；模型卡：https://huggingface.co/qvac/BotPsy-0.8B

## 3. rea-video：从镜头、音频和压缩特征逆向视频结构

**近期项目补录，原始发布日期未单独确认；类型：开源工具。**

**摘要：** rea-video 通过 FFmpeg 等工具拆分镜头和声音，用视频帧特征、元数据、镜头变化、视觉/听觉证据判断各片段更可能采用实拍、生成或代码动画制作，并输出复刻方案和证据报告。

**核心解读：** 从视频信号中提取确定性证据，可减少所有画面都交给大模型猜测的依赖。但经过平台转码的视频可能抹除关键编码噪声和元数据，视觉复核仍必需。

**为什么关注：** 镜头拆分、音乐节拍、字幕与视觉特征判别是多模态内容理解的可组合基础能力。

**pi-67 / AIOS 启发：** 分别验证镜头边界、音频分类、画面类型和内容框架识别；注意它解决的是“怎么制作”，不是已经验证的广告创意框架分类器。

**证据与限制：** 仓库公布的小规模准确率为作者自测，不能视为独立工业级效果。工程成熟度 **65/100**。

一手来源：https://github.com/JuneYaooo/rea-video

## 4. Viggle Remake：保留镜头与音轨的可控视频改写

**近期模型补录，官方模型卡未明确首发日期；类型：视频编辑模型。**

**摘要：** Viggle 提供基于 MiniMax H3 的 `swap` 和 `edit` 两组 LoRA 及 MCP 工作流，尝试替换人物、道具、背景与光线，同时保持原镜头运动、节奏和声音。

**核心解读：** 视频的可控局部编辑比一遍遍全片重新生成更接近规模化生产需求，但连续性、细节与时间轴漂移仍需测试。

**为什么关注：** 可编辑模型与素材授权、商品主体真实性及明确的后处理环节共同决定商业落地。

**pi-67 / AIOS 启发：** 仅用获授权视频测试动作保真、包装文字、分镜一致性、显存和每次成功编辑成本。官方 12–24GB 路线为量化 ComfyUI 手动流程，不应误称为完整自动化可在 12GB GPU 跑通。

**证据与限制：** 权重受 MiniMax H3 Community License 约束，代码 Apache 2.0；模型无法判断人物是否授权。工程成熟度 **64/100**。

一手来源：https://huggingface.co/Viggle/Viggle-Remake

## 5. CopilotKit OpenBot：为每个 Agent 提供计算环境与审计网关

**近期项目补录，原始发布日期未单独确认；类型：开源 Agent Infrastructure。**

**摘要：** OpenBot 是可自托管的 AI coworker 工作台，支持 AG-UI 接入 Agent、独立浏览器/文件环境，并通过策略网关检查和记录工具动作。

**核心解读：** 权限判断、工具执行与审计属于 Harness/Runtime 的责任，不应只是 Prompt 中的“请勿越权”。

**为什么关注：** 企业多 Agent 运行需要隔离、凭据管理、事件可追踪和可控地将成果交付给用户。

**pi-67 / AIOS 启发：** 研究 Agent 计算环境隔离、工具策略和审计，并检验与现有架构的重叠；保持模型和宿主中立。

**证据与限制：** 应用源码 MIT，但 CopilotKit Intelligence 单独授权；官方本地单用户管理员模式不能直接暴露给多人。工程成熟度 **65/100**。

一手来源：https://github.com/CopilotKit/OpenBot
