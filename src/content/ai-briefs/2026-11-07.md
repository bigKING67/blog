# AI Intelligence Daily｜2026 年 11 月 7 日

**核心判断：** 本期高价值变化集中在两条路径：一是用专用决策模型替代 Agent 中大量小型语言判断；二是以可编辑的视频生成与显式世界状态强化复杂多模态生产流程。另有一类主动式 Agent 框架开始以可审查的开源原型形式出现。

本期以 **11 月 6 日的 Kakao 发布、11 月 5 日的 Google/NVIDIA/Hugging Face 发布**为主，补充此前尚未收录的 **10 月 31 日 DeepSeek 主动式 Agent 原型**。截至北京时间 11 月 7 日早间，未将缺少一手证据的当日消息写成已验证长期实体。**所有厂商 Benchmark、质量展示、性能数字均为官方声明，非独立复现。**

## 01｜Kakao Kanana-2-v-decide：3.67B 图文决策模型直接输出概率与选择

**发布时间：2026-11-06｜方向：前沿模型、Agent Router、视觉决策**

**摘要：** Kakao 在官方 Hugging Face 发布 Kanana-2-v-decide-3b-2611，约 3.67B 参数，支持文字和图片输入；其用途不是输出一段自然语言，而是对选项、真假或分数给出结构化决策和概率。权重可以获取，需遵循 Kanana Open License。Kakao 报告 H200 单卡平均耗时低于 0.04 秒，但未独立复现。

**核心解读：** Agent 并非每一次判断都需要完整文本生成。工具路由、标签分类、视觉合格判断等确定输出空间的任务，更适合独立的判定模块。概率输出不等于可靠置信度，候选集变化、语言迁移和视觉困难样本均可能导致偏差。

**为什么值得关注：** 当 Agent 每个任务包含大量微决策时，分离「判断」与「生成」可能降低延迟、格式错误和推理成本。

**对 pi-67 / AIOS 的启发：** 对 pi-67，用真实任务数据比较 decision model 与通用小模型的路由正确率、误判率和延迟；对 AIOS，尝试视频抽帧后的商品属性、镜头类型或素材初筛，但必须维持可回退的验证环节。**成熟度 68/100（可测试），非生产准确率认证。**

## 02｜Gemini Omni 1.2 Flash：15 秒视频、多轮编辑与公开 API 成本

**发布时间：2026-11-05｜方向：AI 视频、生成式多模态、商业内容生产**

**摘要：** Google 公告 Gemini Omni 1.2 Flash 已在 Gemini API 与企业渠道正式可用，支持 3–15 秒视频生成及多轮对话编辑；720p 的官方标价为 **0.07 美元/秒**，比 Omni 1.1 降低约 30%。Google 介绍可通过参考图片、短动作片段与音频线索引导结果，并在后续升级到更高分辨率。

**核心解读：** 视频模型的价值正在从一次性成片转向可局部修订、可保留参考对象、可对不同草稿实施成本控制的工作流。但宣传样片和品牌文字保真展示仍是厂商材料。

**为什么值得关注：** 可公开接入的价格及可编辑接口允许以客观业务集测算「单条合格素材成本」，而不是只比较成片主观观感。

**对 pi-67 / AIOS 的启发：** AIOS 可针对商品主体、包装字样、颜色、镜头运动和编辑残留，建立多轮生成评测；比较一次生成与编辑修复的最终成功率及成本。pi-67 可关注多轮多模态会话状态组织。**成熟度 83/100（适合严肃生产评估），未独立验证品牌内容质量。**

一手来源：https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/

## 03｜NVIDIA Cosmos 3 Nano：把动作和场景状态转化为可交互视频

**发布时间：2026-11-05｜方向：世界模型、开源权重、多模态生成**

**摘要：** NVIDIA 公布四种 Cosmos 3 Nano 专用检查点：Transfer-Auto、Sim-Auto、Sim-Transfer、Sim-Bimanual，分别涉及多视角自动驾驶数据、流式相机与 LiDAR、模拟器状态到 RGB 视频，以及机器人动作到后续画面。每个检查点为约 16B 训练参数的后训练模型，按 OpenMDW1.1 条款开放权重。

**核心解读：** 它们将物理状态、动作、相机与视觉观测的关系显式建模，试图减少长时间生成中的状态漂移。这与通用「提示词生成营销短片」并不是同一任务。

**为什么值得关注：** 连续画面必须受到状态约束，尤其在长时程交互或多镜头一致性应用中。

**对 pi-67 / AIOS 的启发：** AIOS 值得研究可控场景状态、分段生成与时序校验思想；不要将仿真模型误作商业视频的即插即用替代。官方测试硬件和展示无法证明消费级部署可行。**成熟度 66/100（开放可测的研究组件）。**

一手来源：https://huggingface.co/blog/nvidia/cosmos-interactive-world-simulation

## 04｜DeepSeek dsh-superagent：主动式 Coding Agent 原型，但明确非正式产品

**公开时间：2026-10-31｜本期补充收录｜方向：Agent Harness、AI 编程、开源工作流**

**摘要：** DeepSeek Harness 团队公开 MIT 许可的 dsh-superagent-prototype。官方 README 将其定位为单 GitHub 仓库的主动式编码 Agent，可响应获授权的 GitHub 事件及可选飞书消息，建立工作条目，使用独立 Session/目录执行，并通过原讨论或 PR 交付。

**核心解读：** 核心并非“让 Agent 随意自动干活”，而是如何在事件驱动、授权边界、任务归属和人类注意力预算之间形成系统设计。README 特别明确：这是研究原型、并非正式 DeepSeek 产品，部分设想未实现，也不能保证生产可靠性。

**为什么值得关注：** 团队 Coding Agent 正在从问答工具走向长期监听事件的工作主体，而权限与可追溯性决定其是否可靠。

**对 pi-67 / AIOS 的启发：** pi-67 可参考授权事件触发、Work Item、Session 持久化和 PR 交付的设计，但应保持与具体代码托管平台无关；AIOS 可借鉴受控自动任务生命周期。**成熟度 48/100（研究原型），不建议直接生产部署。**

一手来源：https://github.com/deepseek-ai/dsh-superagent-prototype

## 05｜Hugging Face LeRobot v0.7.0：远程模型推理与语言驱动的闭环控制

**发布时间：2026-11-05｜方向：开源工程、Agent 编排、世界动作模型**

**摘要：** Hugging Face 发布 LeRobot v0.7.0，新增交互式 rollout、语言指令切换、外部 VLM Planner、远程策略推理与数据流式加载。其更新还接入多种 world action models 与 VLA，并引入分布式训练能力。GitHub 正式发布记录与维护团队技术文章均可核查。

**核心解读：** 复杂多模态系统逐渐采用“轻量端侧执行 + 远程计算节点 + 外部规划器”的分层组合。运行过程中可以保留状态、切换子任务，并请求视觉理解或高层规划。

**为什么值得关注：** 它展示了开源多模型系统如何处理连续控制、状态保持和远程推理，而不仅是一次性调用 API。

**对 pi-67 / AIOS 的启发：** 参考远端推理服务、上下文持续会话及执行闭环的分层抽象；但机器人控制框架不应直接搬进视频生产系统。LeRobot 是已有持续演进项目，此次版本更新只记入日报，不为版本号重复创建新长期 Entity。
