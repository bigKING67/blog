# AI Intelligence Daily｜2026-11-28

本期精选 11 月 25 日提交、26 日列入 arXiv 最近提交列表的研究及公开项目材料；不是 28 日首发。作者实验不等同于独立生产验证。

## 1. HoMe

**摘要：** 通过失败归因、会话级记忆版本与评测反馈优化记忆系统 Harness，已有 ReMe 插件。

**核心解读：** 优化器、诊断器及案例 Agent 结合两套版本历史，从回答错误回溯到检索、记忆写入或维护机制。

**为什么关注：** 使记忆改进从手工调参转向有证据的版本化实验。

**pi-67 / AIOS 启发：** pi-67 可建立记忆版本、来源、失败归因和留出集评测；AIOS 可借鉴证据生命周期测试。

**成熟度与限制：** 68/100，research。作者报告 LongMemEval-S 留出集从 88.8% 到 91.6%，查询 Token 减少 59.2%；BEAM-1M 从 65.0% 到 70.4%，查询 Token 减少 40.7%。不计记忆构建及优化成本，有个别子类退步，未独立复现。已有代码和文档，未进行本地验证。

一手来源：[原始论文](https://arxiv.org/abs/2611.34624) · [作者仓库](https://github.com/agentscope-ai/ReMe) · [项目文档](https://reme.agentscope.io/en/blog_20261124)

## 2. ProbFaS

**摘要：** 无需训练的任务感知视频帧选择研究，通过多保真高斯过程校准视觉文本相似度与 MLLM 判断。

**核心解读：** 低成本的密集相似度估计与高成本的稀疏模型判断结合，再以时间 DPP 兼顾相关性和覆盖。

**为什么关注：** 单纯抽帧或相似度排序可能遗漏短暂事件；帧预算应与任务证据相关。

**pi-67 / AIOS 启发：** AIOS 可对比均匀、镜头感知和校准采样，测量事件召回、边界误差、完整耗时及成本；检索时再按查询细化。

**成熟度与限制：** 36/100，watch。作者报告在 15 个设置中 13 个领先，部分长视频基准 32 帧达到 128 帧强基线表现。包含额外模型判断，不能直接等同于四倍成本下降；未核验公开实现。

一手来源：[原始论文](https://arxiv.org/abs/2611.34903)

## 3. TransHarness

**摘要：** 从同任务成功与失败轨迹对照提取可迁移的 Harness 干预策略。

**核心解读：** 将触发条件与诊断指引配对，并使用跨任务重放和独立语义选择降低对原始解法的依赖。

**为什么关注：** 同一评测集上的优化可能过拟合，必须测量跨仓库和跨任务迁移。

**pi-67 / AIOS 启发：** pi-67 可将失败轨迹沉淀为条件化检查，使用未参与优化的任务集做消融、回归和成本测试；AIOS 同样可评估跨内容类别迁移。

**成熟度与限制：** 35/100，watch。作者报告 300 条测试分布之外的源轨迹，在 DeepSWE v1.1 和 Terminal-Bench 2.1 分别达到 76.4% 和 95.5%；未独立复现，未确认公开实现。

一手来源：[原始论文](https://arxiv.org/abs/2611.33757)

## 4. Agentic LongLive

**摘要：** 异步 Agent 为流式长视频生成维护人物、物体和场景的图文状态。

**核心解读：** 记忆 Agent 并行处理已出现的提示词，形成实体图像与镜头参考，避免把生成错误直接写回记忆；生成端使用注意力 sink 接入参考。

**为什么关注：** 把跨镜头一致性显式建模为长期状态，同时避免串行记忆更新拖慢生成。

**pi-67 / AIOS 启发：** AIOS 可借鉴版本化人物、商品、场景状态与镜头参考图；闭源生成 API 只能通过公开参考输入能力适配，不假设能修改 KV cache。

**成熟度与限制：** 39/100，watch。作者报告 25 个故事、857 个镜头，持续状态准确率提升 26.3 点，主角身份提升 44.9 点。实时演示依赖多卡 B200；时间开销不代表总算力成本。项目页已核验，代码与权重具体可用性未核实。

一手来源：[原始论文](https://arxiv.org/abs/2611.34907) · [项目文档](https://nvlabs.github.io/LongLive/Agentic-LongLive/)

## 5. SkillsBench Lift Reanalysis

**摘要：** 对 SkillsBench 的源码级审计与采样噪声再分析，公开复现脚本及审计材料。

**核心解读：** 审查 7554 次试验和 1421 个配对单元，识别评分器依赖、空技能目录、宿主内建技能等混杂因素；校正多重比较后未发现显著的任务级负提升。

**为什么关注：** 少量重复实验中的负收益不能证明 Skill 有害，路由策略可能从噪声中学习。

**pi-67 / AIOS 启发：** pi-67 可使用固定宿主、控制内建技能、独立验收和留出集评估 Skill；AIOS 可用同一方法评价创作工作流组件。

**成熟度与限制：** 58/100，research。这不是所有 Skill 都有益的证明；研究仓库提供 MIT 代码及复现材料，原始轨迹和上游文件有外部依赖，未自行复现。

一手来源：[原始论文](https://arxiv.org/abs/2611.33943) · [作者仓库](https://github.com/rrrrr4788/skillsbench-lift-reanalysis)
