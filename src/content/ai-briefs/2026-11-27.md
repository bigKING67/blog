# AI Intelligence Daily｜2026-11-27

本期精选 11 月 25–26 日公开技术材料。作者实验和发布方报告不是独立验证。

## 1. VibeVideoAgent：为代码驱动视频增加感知验证闭环

**摘要：** KlingAI Research 11 月 25 日提交论文，将音视频感知放入独立短生命周期上下文，编码 Agent 只接收精简、可定位的证据。通过七类 MCP 工具检查草稿、参考媒体、局部事件及需求。

**核心解读：** 渲染程序正常退出不意味着画面或音轨正确；先用最小预览验证高风险设计，再组装和局部修复。

**为什么关注：** 作者在 239 个任务上报告 Opus 5.5 整体视听质量评分 4.03→4.43；仍有较大编码输出成本，未独立复现。

**pi-67 / AIOS 启发：** 建立独立于渲染引擎的媒体检查接口，统一时间坐标，结合无模型调用的冻结帧、音量、静音等探针与多模态验收。37/100，论文阶段，未确认公开实现。

一手来源：https://arxiv.org/abs/2611.34237

## 2. EvoLink-Bench：检验 Agent 是否真的从历史任务中学习

**摘要：** 北航研究团队 11 月 25 日提交论文，并发布评测器、适配器、示例和离线测试。区分事实知识修订和执行能力学习。

**核心解读：** 比较每轮重置、保留状态但不显式更新、保留状态且更新三种条件，评价后续任务复用与迁移。

**为什么关注：** 作者报告五种框架、三种骨干配置、19,635 个评分任务槽位的实验，持久化不一定提高后续表现。结果为描述性比较，并不自动建立因果关系。

**pi-67 / AIOS 启发：** 用跨任务依赖测试评价记忆、Skills 和经验更新；将失败恢复、知识修订、能力迁移和负迁移分开测量。64/100，MIT 项目代码，第三方数据及完整复现前提须分别核验。

一手来源：https://arxiv.org/abs/2611.34400 ；https://github.com/BUAA-Self-Evolving/EvoLink-Bench

## 3. MeterRouter：将货币预算纳入多 Agent 协作图

**摘要：** 11 月 25 日论文提出按问题和预算选择角色、模型、通信边与终止时机的动态路由器，采用模仿学习与 GRPO 变体优化正确性和成本。

**核心解读：** 多 Agent 成本不仅取决于模型单价，还取决于通信拓扑、上下文和运行步数。

**为什么关注：** 作者在五项基准报告相较强多 Agent 路由基线成本下降 82%，不能外推到具体应用。

**pi-67 / AIOS 启发：** 从单 Agent 开始，在有明确预期增益时才扩展角色或升级模型；由执行层实施硬预算、预留费用与退出规则。34/100，论文阶段，未核实公开代码。

一手来源：https://arxiv.org/abs/2611.34327

## 4. Hugging Face：训练小模型 Agent 团队学会通信

**摘要：** 11 月 26 日公布四个共享 Qwen3-0.6B 策略的 Agent 协作实验和 TRL 复现示例。各 Agent 掌握局部信息，通过消息协作完成可验证排序任务。

**核心解读：** 使用团队级奖励优化通信与任务完成，而不是默认增加角色或重试次数就会改善性能。

**为什么关注：** 原始训练窗口成功率 6.56%→82.34%，每团队生成 token 约 12.8K→8.0K；留出集仅 32 题，未保留对应的留出 token 效率数据。另有较短复现实验，不应外推复杂工程。

**pi-67 / AIOS 启发：** 对照单 Agent、未训练团队、训练团队的成功率、总 token、延迟和通信开销；先验证任务可分解性。工程方法案例仅收录简报。

一手来源：https://huggingface.co/blog/training-swarms

## 5. Inkling 2 Mini：用 Coding Agent 迭代推理服务配置

**摘要：** 11 月 25 日 Hugging Face 工程文章公开单张 96GB RTX PRO 6000 的 46 次有效实验，配合 vLLM nightly 和 DSpark 推测解码，单用户解码 136→190.6 token/s，八用户总吞吐约 570→716 token/s。

**核心解读：** 通过基准、控制实验、预热、显存和错误日志诊断逐步搜索配置；硬件带宽与专家访问模式限制进一步收益。

**为什么关注：** 作者报告贪心输出一致并公开脚本、日志与原始测量；不等于所有采样配置或其他显卡可获得相同提升。

**pi-67 / AIOS 启发：** 将推理优化做成可审计实验任务，固定版本、输入和正确性门槛，分别评价预填充、解码、峰值显存与并发。此为已有模型的工程实验，并非新模型发布；已有 Inkling Entity 在待合并 PR #33，本次不重复创建。

一手来源：https://huggingface.co/blog/inkling-2-mini-inference-hillclimb ；https://github.com/NielsRogge/inkling-2-mini-hillclimb
