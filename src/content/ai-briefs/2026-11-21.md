## 1. Inkling 2 Mini：开放权重的循环 MoE 多模态 Agent 模型

**发布日期：2026-11-20；类别：开放模型 / Coding / 图文理解。**

**摘要：** Thinking Machines Lab 发布 Apache 2.0 的 Inkling 2 Mini，26.4B 总参数、3.4B 原始激活参数，循环结构三次运行后约 5.4B 有效活跃参数。支持文字、图片输入和文字输出，官方给出开放权重、量化及本地运行指引。

**核心解读：** 比起单纯缩小参数量，循环层与稀疏专家组合探索了利用可重复计算提升小活跃量模型能力的路线。这里的「Mini」不意味着模型文件仅有 3.4B 参数大小。

**为什么关注：** 官方模型卡给出约 20GB 检查点，以及 Apple Silicon、NVIDIA 的推理支持途径；发布方的 Agent 与 Coding 成绩虽吸引人，仍需在统一 Harness 和预算下复测。

**pi-67 / AIOS 启发：** pi-67 优先测试工具调用、长任务编程、上下文压缩以及单位成功任务成本；AIOS 可对图像分类开展评测。官方输入模态未声明原生视频，因此不应直接替换视频时间戳理解链路。工程成熟度 76/100，研究与评测候选。

一手来源：https://thinkingmachines.ai/model-card/inkling-2-mini/

## 2. Codex CLI 0.171.0：远程任务执行与可检索的多 Agent 工作区

**发布日期：2026-11-20（GitHub Release 时间）；类别：AI 编程 / Agent Runtime。**

**摘要：** OpenAI Codex CLI 0.171.0 把 GPT-6.2 Sol/Astra 放入模型目录、默认使用 Sol，并默认开启有文件与图片预览、子 Agent 对话记录的 TUI Workspace。新增远程非交互执行：codex exec --remote 可对接现有 App Server 并启动或恢复会话。

**核心解读：** Coding Agent 正在将远程执行、任务恢复、文档证据与子任务过程放到统一工作台，而不是只展示一个聊天窗口。版本同时修复线程切换时输入草稿丢失及审批状态错位等问题。

**为什么关注：** 远程持久任务与可审查的子 Agent 轨迹对开发质量、效率与排错直接重要。不过该命令并不意味着无条件提供云端托管沙箱：仍需自行部署及保护远程 App Server。

**pi-67 / AIOS 启发：** 可参考运行控制面与执行面分离、会话持久化、可搜索证据和审查流程，保持跨 Agent Host 中立。此为现有 Codex 的版本更新，仅记入日报，不创建重复长期项目实体。

一手来源：https://github.com/openai/codex/releases/tag/rust-v0.171.0

## 3. Hermes Agent v0.23.3：上下文缓存、压缩和工具结果治理进入同一生命周期

**GitHub 发布于 2026-11-20 UTC；类别：Context Engineering / Agent Gateway。**

**摘要：** Nous Research 发布 v0.23.3 正式补丁版，更新涉及 Prompt Cache 生命周期（包括长工具调用期间保持缓存、会话空闲时压缩）、被压缩工具结果归档、默认启用主动工具结果裁剪，以及存储层与 SQLite 后端解耦等。

**核心解读：** 持续运行的 Agent 面临的不只是 Context Window 长短，更包括缓存失效时机、工具输出污染和跨端持久存储一致性。上述措施面向系统稳定性与成本，而不是新模型的能力提升。

**为什么关注：** 多会话 Agent 的持续运行成本可能被缓存和压缩策略显著影响，必须单独测试不同工作负载的 Token、恢复正确率与关键信息损失。

**pi-67 / AIOS 启发：** 参考缓存生命周期、可追溯工具输出归档和可替换存储接口，注意控制不同用户和租户的数据边界。已有 Hermes Agent 长期实体应更新 timeline，不再新建。成熟度 88/100 为工程评测就绪判断，非独立质量排名。

一手来源：https://github.com/NousResearch/hermes-agent/releases/tag/v0.23.3

## 4. ScaleWorld：一个骨干统一低分辨率世界预测和高分辨率细化

**论文 2026-11-19 提交；类别：世界模型 / 视频生成。**

**摘要：** ScaleWorld 让同一因果视频骨干先预测低分辨率视频块，再进行一次高分辨率细化。两类任务分别维护长低分辨率历史和短高分辨率历史，并通过任务非对称在线策略蒸馏将专家能力合入单模型。

**核心解读：** 模型将「预测时间发展」与「补充细节」分成不同分辨率和记忆长度，有机会避免全部时序都在高分辨率上做昂贵计算。

**为什么关注：** 多镜头一致性及高分辨率成本是视频生成落地的重要约束。作者的质量和效率结果属于原始论文报告，公开代码、推理成本与商业任务表现仍待核查。

**pi-67 / AIOS 启发：** AIOS 可以参考粗到细的分段生成与状态管理，并在可复现条件具备后比较时序连续性、峰值显存、重渲染成本。并不是现成的广告视频理解或剪辑模型。研究成熟度 32/100。

一手来源：https://arxiv.org/abs/2611.26615

## 5. RL Post-Training in Diffusion Transformers Is Activation Steering：固定小向量复现部分生成后训练收益

**论文 2026-11-19 提交；类别：图像与视频生成 / 高效后训练。**

**摘要：** 作者在冻结的扩散 Transformer 层输出上添加与输入无关的固定 Steering Vectors。论文报告，在 SD3.5-M 中 0.29M 向量参数比 18.8M 的 RL LoRA 少约 65 倍；在部分图像与视频实验里复现了大部分特定奖励提升。

**核心解读：** 特定强化学习质量改善可能相当程度来自模型内已有能力方向的重新引导，而不完全是新学到复杂输入依赖变换。该解释在论文实验范围内成立，不能直接泛化到所有生成模型。

**为什么关注：** 如果后续跨模型、跨数据验证成立，可能为低成本的视觉生成风格和偏好适配带来新路线。

**pi-67 / AIOS 启发：** 未来评测时应同时看文字渲染、商品细节保真、人类盲评、跨分布泛化和计算成本，不应只比较奖励指标。研究成熟度 35/100。

一手来源：https://arxiv.org/abs/2611.26627
