# AI Intelligence Daily｜2026-11-22

**核心判断：** Agent 的后训练开始与真实执行 Harness 深度结合；低参数量语音识别、文本检索模型继续改善本地服务可行性；视频创作平台则在把生成、编辑和音频衔接到同一时间轴。

今天为周日，精选经一手核验的 **11 月 17—20 日**近期重要发布，而非声称五项均在 11 月 22 日首发。所有厂家自报成绩均以发布方实验对待，不作独立验证结论。

## 1. Hugging Face Harness Adapters：让模型在真正使用的 Agent Harness 内学习

- **摘要：** 11 月 20 日，Hugging Face 公布 Qwen3.8-27B 在 Pi、OpenCode、Hermes Agent 三种实际 Harness 中进行强化学习后训练的方案，公开专用 LoRA、合并适配器、数据与运行工件。作者称 Pi 下 Terminal-Bench 2.1 pass@1 从 39% 升至 55%，平均 Token 从 2.9K 降至 1.5K。
- **核心解读：** 相同模型在不同 Harness 的工具格式和执行反馈中表现不同；训练时使用真实 Harness 轨迹比单纯模拟工具调用更接近生产。但三种 Harness 自身配置不同，不能把各自跑分直接排名。
- **为什么值得关注：** Harness、任务分布和模型权重开始成为共同优化的对象，而不是只为 Agent 寻找一个更强的通用模型。
- **pi-67 / AIOS 启发：** 构建固定任务、独立验证器和工具调用日志，先做跨 Harness 评测，再考虑 LoRA/RL 专项优化。验证任务成功率、每成功任务成本、跨领域泛化；不要把厂商提升当成已复现结果。
- **成熟度：** 68/100，research；已有公开资源，但独立验证不足。

一手来源：https://huggingface.co/blog/harness-adapters-at-scale
模型与工件：https://huggingface.co/collections/harness-hub/qwen38-27b-harness-adapters

## 2. Rumble-2-Flash：0.5B 多语言开放 ASR 模型

- **摘要：** 11 月 18 日，Reson8 开放 Apache-2.0 权重的 Rumble-2-Flash，0.5B 参数，支持 40 余种语言及原生 Transformers/vLLM。模型卡公布中文和多语种评测。
- **核心解读：** 小参数模型经蒸馏后可成为高频转写的实际候选；但模型吞吐与音频质量强烈依赖硬件、批次和语料。发布方展示的 7000+ RTFx 是特定 H200 和充分批量条件，不是普通显卡保证值。
- **为什么值得关注：** 多语言口播内容处理的规模化成本可能继续下降；真实噪声和专有名词仍决定实际可用性。
- **pi-67 / AIOS 启发：** 作为 ASR 候选对照已有转写方案，在中文商业口播、BGM 干扰和口音样本上测 CER、时序对齐、显存、每条视频成本。它不是音色、声纹或音效模型，无需重复扩建职责。
- **成熟度：** 72/100，research；权重、许可与基础推理接口已可核验。

一手来源：https://huggingface.co/Reson8/Rumble-2-Flash
发布说明：https://huggingface.co/blog/rumble-2-flash

## 3. NeuML Atto：几十 K 参数也能做文本检索吗？

- **摘要：** 11 月 19 日，NeuML 公开 Atto 模型系列设计及检索结果，覆盖 dense、sparse、ColBERT 形式；从 840 参数的极小实验到 28M 参数模型。
- **核心解读：** 使用较小内部上下文处理空间、再投影到较宽向量表征，是其效率研究重点。作者在三个 BEIR 英语数据集上比较了小模型与更大嵌入模型。
- **为什么值得关注：** 垂直领域 RAG 可能不必一律使用大型 Embedding，但英语数据和有限数据集不支持跨语言、多模态的宽泛结论。
- **pi-67 / AIOS 启发：** 只把它加入中文文档检索的离线评测候选，对比召回、nDCG@10、索引大小、延迟及领域迁移；不要宣称其能直接实现视频语义检索。
- **成熟度：** 62/100，research；已公布模型与初步结果，工程普适性待检验。

一手来源：https://huggingface.co/blog/neuml/introducing-atto

## 4. Suno Visuals：音乐与图片、视频、口型和时间线编辑开始融合

- **摘要：** Suno 11 月 17 日发布 Visuals，在 Web 和移动端将音乐、图像生成、短视频、Lip Sync、歌词视频与可延长组合的 Sequences 放到同一创作流程。
- **核心解读：** 价值不只在生成一段视频，而在将声音作为主时间轴，持续调整画面、歌词、口型与多片段编排。
- **为什么值得关注：** 有音乐/音频基准的视频编辑能够让音画协调成为产品原生能力，而非最后一步依赖人工整理。
- **pi-67 / AIOS 启发：** 研究音频驱动分镜、节拍对齐、歌词/台词层、片段延长及局部再生成的界面与工件表示；当前主要定位音乐内容创作，不应推断有商业广告自动混剪 API 或可自由商用生成权利。
- **成熟度判断：** 已有正式产品，但没有进行独立生产评测；仅列当日 Brief，不新建既有公司长期实体。

一手来源：https://suno.com/release-notes/visuals
产品文档：https://help.suno.com/en/articles/14661121

## 5. Microsoft Agent 365：跨平台 Agent 身份、权限和运行时治理

- **摘要：** 微软在 11 月 17 日 Ignite 2026 公布 Agent 365 治理扩展，涉及跨供应商 Agent Registry、Entra Agent ID、动态风险、当地 Agent 的 DLP/执行限制及多租户管理；不同功能分属一般可用、Preview 或有限 Preview。
- **核心解读：** 企业 Agent 不只需要历史记忆，还要有主体身份、明确的组织权限、工具授权、审计日志和风险动态处理。
- **为什么值得关注：** Agent 普及后风险从错误回答扩展为实际数据访问和系统操作；运行时强制边界不能只交给 Prompt。
- **pi-67 / AIOS 启发：** 参考身份、授权、执行沙箱、审计与多租户隔离的分层治理方法；优先明确单 Agent 可访问的数据范围和升级权限流程，不必绑定单一平台。
- **成熟度判断：** 基础平台已有商业部署；本次主要为现有平台增量，暂不新建长期 Entity，也不把预览特性描述为全量上线。

一手来源：https://techcommunity.microsoft.com/blog/agent-365-blog/whats-new-in-microsoft-agent-365-ignite-2026/4571753
