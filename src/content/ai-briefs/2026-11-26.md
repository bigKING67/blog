# AI Intelligence Daily｜2026-11-26

本期覆盖 11 月 19–25 日的一手公开材料。早期研究为高价值补录，不宣称全部当天首发；发布方数据均未独立复现。

## 1. WeMM-Video：小型模型联合理解画面和原声

**摘要：** 11 月 19 日技术报告介绍腾讯微信视觉与清华研究人员的 2B、4B、9B、35B-A3B 中英双语模型系列。公开 2B 和 4B 权重，支持视频画面与音轨联合输入。

**核心解读：** 视频理解需要联合感知时序、口播与声学信号；4B GGUF 三组件合计约 7.53 GiB，不等于实际显存占用。需使用支持完整视听路径的运行时。

**为什么关注：** 小模型可以进入本地视听理解的对照评测。作者报告 4B Thinking 在 Video-MME 有音频版为 83.9，Video-MME-v2 有音频版为 48.1，不足以证明特定应用优于现有模型。

**pi-67 / AIOS 启发：** 评测全模态与无音频消融、时间定位、结构化输出、延迟、显存和单位任务成本。74/100，具备实测条件，未独立验证。

一手来源：https://arxiv.org/abs/2611.26409 ；https://github.com/Tencent/WeMM-Video ；https://huggingface.co/tencent/WeMM-Video-4B-GGUF

## 2. Anthropic：用生产流量验证 Rust API 迁移

**摘要：** 11 月 25 日工程复盘披露 Python 到 Rust 的 Messages API 迁移；官方报告单请求 CPU 用量下降约 70%，首 token 中位延迟下降约 20%。

**核心解读：** 两版本共享同次模型输出、逐阶段比较，以差异指纹定位问题；沙箱内修复、影子生产验证、复盘规则和持久测试形成三层闭环。

**为什么关注：** AI 编程瓶颈转向独立验证，而非代码生成速度。官方结果不代表任意迁移都有相同收益。

**pi-67 / AIOS 启发：** 将旧系统作为差分验证器；把可复现失败、人工批准后的规则及回归检查纳入工程流程。应分离验证和执行权限，避免记录敏感原始请求。本项为既有产品工程案例，仅纳入简报。

一手来源：https://www.anthropic.com/research/migrating-api-to-rust

## 3. VideoJSON：让 Agent 编程检索结构化视频记忆

**摘要：** 11 月 20 日论文把每分钟视频描述、事件、实体和转写存为 JSON，并在查询时让 Agent 在沙箱中编程查找跨时段证据。

**核心解读：** 记忆存储可保持简单，复杂性放到可控查询执行层。结构化记录丢失的信息仍可能无法恢复。

**为什么关注：** 作者在超长视频基准报告相对 MAGIC-Video 的提升，尚未独立复现；论文称代码将在发表后公开。

**pi-67 / AIOS 启发：** 研究镜头级/事件级索引、向量与结构化查询组合、时间证据引用和原视频回查。35/100，论文阶段。

一手来源：https://arxiv.org/abs/2611.28167

## 4. FineProofEnvs：小模型训练的可审计验证环境

**摘要：** 11 月 24 日发布 Qwen3.5-2B 数学证明 RL 复现实验及开放工件，报告 500 次更新后评分 0.217→0.407。

**核心解读：** 裁判质量、训练数据去重、截断策略和轨迹管理影响优化结果；抽查仍发现满分证明含错误。

**为什么关注：** 一次实验约 28 小时、820 美元，为小模型专用后训练提供具体参考；仅 64 道评测题，不能推广。

**pi-67 / AIOS 启发：** 先建立任务、确定性检查和独立裁判，再研究后训练；不将奖励分数当成最终质量。63/100。

一手来源：https://huggingface.co/blog/FineEnvs/fineproofenvs-rl-2b-prover ；https://huggingface.co/FineEnvs/Qwen3.5-2B-FineProof-RL

## 5. RoboTrack：轻量点跟踪与真实操作数据

**摘要：** Ai2 11 月 23 日发布点跟踪研究，包含合成训练数据、真实评测、17M 参数轻量模型与较大 Warp 模型。

**核心解读：** 通过点位置与可见性维护跨帧运动证据，补充语义描述；合成数据的运动分布需匹配目标视频。

**为什么关注：** 有公开模型和数据，轻量模型可作为局部运动评测候选。机器人实验不等于商业视频质量验证。

**pi-67 / AIOS 启发：** 研究商品局部关键点、遮挡和跨帧一致性；RoboTracker 为 Apache-2.0，Warp 权重为非商业许可，第三方数据需分别核验。65/100。

一手来源：https://huggingface.co/blog/allenai/robotrack ；https://github.com/allenai/robotrack
